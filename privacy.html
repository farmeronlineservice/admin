Privacy Policy

Farmer ID Generator (Agristack) · Last updated: September 2026

This extension helps authorized retailers generate printable Farmer ID cards from official Agristack government portals. This policy explains what data we process and why.

1. Data we process

  • Account data: name, mobile number, password (stored for login), address (optional), token balance.
  • Usage logs (minimal): retailer name/mobile, Farmer ID number, farmer name, taluka, district, state, farmer mobile (if shown on portal), CSC User ID, portal URL, tokens left. We do not store Aadhaar, date of birth, gender, father name, enrolment ID, or identifier type/name in logs.
  • Technical: extension version, last seen time (for support/updates).

2. Why we process it

  • Authenticate retailers and manage token-based access.
  • Prevent duplicate token charges on reprint of the same Farmer ID.
  • Provide admin support for wallet top-ups and account status.
  • Improve reliability of card generation on Agristack pages.

3. Where data is stored

Account and log data are stored in a cloud database (Firebase Realtime Database) configured by the extension operator. Session info is also kept in Chrome local storage on your device.

4. Sharing

We do not sell personal data. Data is accessible only to the extension operator (admin) for account and wallet management. Data may be disclosed if required by law.

5. Security

Access should be protected with Firebase Security Rules and strong admin controls. Users should not share passwords. Production deployments should hash passwords and enable authentication.

6. Your choices

  • You can stop using the extension and request account deactivation from the admin/support contact shown in the app.
  • Do not use the extension if you do not agree with this policy.

7. Government portals

This extension runs only on official Agristack domains and reads page content needed to build a printable card. It is not affiliated with the Government of India. Users must comply with portal terms and local law.

8. Contact

For privacy requests, contact the support number / WhatsApp shown inside the extension after login or on the wallet page.
